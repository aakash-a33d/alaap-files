# resources

Non-code assets. Brand, design source, written content, media and email templates.

`content/` is the reviewed copy that ships in the product: legal text, community
guidelines, help articles, crisis copy, onboarding copy and AI transparency
explanations. Crisis copy and AI disclosure strings are clinically reviewed before
they change — the runtime strings live in `metadata/safety` and `metadata/ai`, and
this directory holds the long-form source they are drawn from.
