# security

Security and privacy governance artifacts, kept in the repository so they version with
the code they describe.

Threat models, security policies, key management procedures, penetration test scope
and reports, vulnerability management, incident response playbooks, vendor security
reviews, SBOMs, compliance evidence, and the privacy review record for each feature
that touches personal data.

A feature that reads identity, clinical or emergency data does not ship without an
entry in `privacy-reviews/`.
